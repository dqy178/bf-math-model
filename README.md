# 高炉检测软件数学模型计算器

把《高炉检测软件数学模型.xlsx》中的 23 个计算模型，重做成一个 **Streamlit 多 Tab 独立计算器**。

打开工具后是一排平铺的 Tab，点进哪个 Tab 就只显示那个模型的 **输入框 → 计算公式 → 计算结果 → 经验范围比对**。
各 Tab 的参数、结果、经验区间完全隔离，**互不联动**。

---

## 快速开始

```bash
# 方式一：双击 启动.bat（自动装依赖并启动，浏览器打开 http://localhost:8501）

# 方式二：命令行
pip install -r requirements.txt
streamlit run app.py
```

本机验证环境：Python 3.13.9 + Streamlit 1.51.0（Anaconda）。

## 每个 Tab 的结构

```
┌─ 模型标题 / 副标题 / 分类 / 对应原表工作表 ────────────┐
│ 说明（模型适用范围、争议点）                          │
├─ 输入区（两列排布，分组）                             │
│    [参数输入框]          [参数输入框]                 │
│    [公式版本下拉]        [口径开关]                   │
│                        [ 计算 ]  ← 点此才计算          │
├─ 计算公式（折叠）                                      │
│    LaTeX 排版公式 + 原表 Excel 公式                    │
├─ 计算结果                                             │
│    ┌─────────┐ ┌─────────┐ ┌─────────┐               │
│    │ 主指标   │ │ 主指标   │ │ 主指标   │               │
│    │ 数值     │ │ 数值     │ │ 数值     │               │
│    │ 区间条    │ │ 区间条    │ │ 区间条    │               │
│    │ ● 正常   │ │ ● 偏高   │ │ ● 偏低   │               │
│    └─────────┘ └─────────┘ └─────────┘               │
│    ▸ 中间量 / 辅助结果（折叠）                          │
│    ▸ 与 Excel 原表数值对照（折叠，含偏差列）            │
│    ▸ ⚠️ 已知问题与原表批注                            │
└──────────────────────────────────────────────────────┘
```

**经验范围比对**：每个结果卡片下有一条区间条，绿色段为经验正常区间，竖线为当前值，
并给出 `● 正常 / ● 偏低 / ● 偏高` 判定。展开「现场标定区间」可直接改上下限，
**改完立即按新区间重新判定**，改动只在本 Tab 生效。

区间来源分三类，界面上会标注：

- `Excel 综合表「3 经验参数范围」` —— 原表综合计算表 R41:R47 自带的六项基准
- `工程参考值（待现场标定）` —— 本工具按高炉冶金常识补充，需按本厂数据标定
- `现场报表实测值（待核对）` —— 原表批注里记录的报表值

## 数据隔离的实现

- 每个模型的输入值存 `__inp__<model.key>__<input.key>`，结果存 `__res__<model.key>`，键名互不冲突；
- 每个模型是一个独立类，**模块之间不 import 彼此的计算函数**，无共享可变状态；
- 计算只在点击本 Tab 的「计算」按钮时触发（`st.form`），不会跨 Tab 触发；
- 经验区间的现场标定值也按 `__res__<model.key>__rng__<result.key>__lo/hi` 独立存储。

## 公式版本对照（发现并保留的原表差异）

很多模型在原表里同时存在多套写法。本工具把它们做成下拉开关，可在同一套参数下对比：

| 模型 | 版本选项 | 说明 |
|---|---|---|
| 理论燃烧温度 | 公式B / 公式A / 原表 G-L 写法 | 湿度定义 % vs g/m³；原表 G/L 写法的 `(273.15+BT)` 位置与 `10^0.7` 指数有笔误，偏差 −1.23 ℃ |
| 鼓风动能 | 经验式 / 标准动能式 | 两式量纲不同；标准式的标准大气压项 (0.101 vs 101.325 kPa) 亦可切换 |
| 炉腹煤气量 | 富氧量是否 /60；是否计含氢产气 | 对应原表批注「含氢量为 0 时与斌鑫数据一致」 |
| 安全容铁 | 文献式 / 原表式 | 原表式多乘炉缸容积，量纲不自洽 |
| 冶炼强度 | ÷时间 / ×时间 | 对应原表批注「应该是除以时间不是乘」 |
| 冶炼周期（批） | Σ(mᵢ·aᵢ) / Σ(mᵢ/aᵢ) | 对应原表批注「质量除以体积而不是乘」 |
| 耐材厚度 | 修正式 / 原表式 | 原表式 a×δt 在分子、M 在分母，量纲不自洽 |
| 落点计算 | 弧度制 / 度制 | 原表把角度 6 直接送入 TAN/SIN/COS（Excel 按弧度算） |
